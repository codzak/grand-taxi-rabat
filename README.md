# Grand Taxi Rabat

A mobile app for grand taxis in Rabat. Find the right stand, see where it goes and the price, choose exactly where you get off, and tell the driver from your phone. Drivers see every drop-off on a map, with an alert before each one.

Status: early. Data and a web prototype exist, the mobile app is being set up.

- `AGENTS.md`: rules for AI agents and contributors
- `docs/`: spec, architecture, pitch notes, mockup, cahier des charges (PDF, French)
- `data/`: stands of Rabat (GeoJSON)
- `prototype/`: first Leaflet web prototype

Map data © OpenStreetMap contributors. Tiles by OpenFreeMap.
